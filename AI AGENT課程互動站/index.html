第 0 章

認識 AI Agent

AI 是你的員工：AI 是聰明但需要你交代的員工，Agent 是會自己動手做完的員工。

💡 核心概念

AI 是什麼？

AI 是「會回答問題的聰明機器」。就像一個很聰明但需要你交代的員工——你問它，它回答。

AI Agent 是什麼？

Agent 是「會自己動手把事做完」的員工。你交代一句話，它會自己規劃、動手、檢查、交差。

🏢 員工對比

比較AI（一般）AI Agent
你問它回答你回答你，還動手做
需要你每一步都要交代交代一句，自己完成
舉例「蘋果是什麼？」「幫我做一個自我介紹網頁」

✏️ 小測驗

1AI 和 AI Agent 最大的差別是什麼？

AI Agent 除了回答，還會自己動手把整件事做完。

2把 AI Agent 想成員工，什麼行為最像？

Agent 會自己規劃步驟、動手做、檢查結果，就像能幹的員工。

3「幫我做一個自我介紹網頁」這種指令，交給誰最適合？

這是一個「要動手做」的需求，正是 Agent 的強項。

📌 本節重點

AI Agent 是會幫你「動手做事」的工具，不是只會回答問題。接下來的課程，你要學的就是怎麼當一個好老闆，把工作交代給它。
