【說明】為什麼學這章
上一章員工進公司了，但它現在還是個「空殼」——打字進去沒有反應。
OpenCode 只是「駕駛座」，它自己不會思考；
你必須先幫它接上一顆「腦袋」（AI 模型），它才會回話、才會做事。

這一章有兩大任務：

- 任務一：接上大腦（讓它活起來）
  申請免費金鑰 → 連接 OpenCode Zen → 專案設定 → 選免費模型
  → 用「建檔案測試」驗證它真的能動手。
- 任務二：讓 AI 幫你把環境建好（讓它長出手腳）
  把「懶人包」貼給它，叫它自己安裝 Git、Node.js 等工具——
  這是你第一次親眼看到 AI Agent「聽懂目標→自己規劃→動手做完→回報」。

用僱用員工來比喻：
- API 金鑰 = 員工的識別證＋發薪帳戶，沒有它 AI 只會發呆
- 專案資料夾 = 給員工一間乾淨的辦公室
- 懶人包環境建置 = 叫員工自己跑建材行、自己施工、自己驗收，
  最後交一張報告給你看

═══════════════════════════════
【操作步驟】
═══════════════════════════════

─────────────────────────────
第一步：申請 OpenCode Zen 免費金鑰
─────────────────────────────
「OpenCode Zen」是 OpenCode 官方的模型總機：
一組金鑰通到多個模型，其中一批目前免費，
不用一家一家去申請 OpenAI、Google 的帳號。

⏸ 授權點（請停下來，這一步要你親自動手）：
金鑰是你的私密資料，AI 不能幫你申請、也不可以亂猜。

1. 開瀏覽器前往：https://opencode.ai/auth
   （網址若轉跳到 auth.opencode.ai 是正常的官方登入頁，不是釣魚。）
2. 用你的 Email 註冊並登入。
3. 進入管理後台（Console），找到 API Keys 區塊，
   點建立新金鑰（按鈕可能叫 Create API Key 或 Add API Key）。
4. ⚠️ 金鑰通常只顯示一次，立刻複製存好！
   保管建議：先貼到記事本暫存，確認整串在同一行、
   前後沒有多餘空白；不要貼到班級群組或共用文件，
   也不要放進之後要上傳 GitHub 的資料夾。

💡 如果後台要求先填付款／帳單資料才能建金鑰：
先試著直接建立；真的被擋下來，公務機或不想綁卡的同學，
到這裡先停下來問承辦，不要在課堂上趕著輸入信用卡。

─────────────────────────────
第二步：在桌面版連接 OpenCode Zen（＋一定要重啟）
─────────────────────────────
1. 打開 OpenCode 桌面版
2. 進入 Settings（設定）
3. 找到 Providers（供應商）這一區
4. 找到「OpenCode Zen」（找不到就用搜尋框打 zen）
5. 點 Connect（連接）
6. 把第一步複製的金鑰貼上，按確認
7. ⚠️ 完全關閉 OpenCode 再重新開啟！

第 7 步不要跳過：新加的供應商常常要重啟才會出現在模型清單裡。
（白話：發完識別證要讓員工重新進門一次，證才生效。）

⚠️ 小心選錯：清單裡有一個長很像的「OpenCode Go」，
那是付費訂閱制方案。本課程只走 OpenCode Zen。

─────────────────────────────
第三步：專案與語系初始設定
─────────────────────────────
1. 新建專案，指定本地資料夾
   先在你的電腦上新增一個全新的空資料夾（例如：Open Code 0517），
   再讓 OpenCode 打開它當作工作的地方。
   就像給員工一間「乾淨的辦公室」，他才不會弄亂你的檔案。
2. 進 Settings 把介面語言改成「繁體中文」。
3. 點選「建立 Git 資料庫」（Git = 時光機，每次改動都有備份點）。
   💡 若此時電腦還沒有 Git，這格可能無法生效——別緊張，
   等第五步 AI 把 Git 裝好後，跟它說一聲就補上了。

─────────────────────────────
第四步：選一顆免費的大腦
─────────────────────────────
1. 打開模型清單（Models），挑「名字有 Free 的」模型，
   例如 DeepSeek V4 Flash Free（200K 上下文，講師實測好用）。
2. 免費款會變動（官方說是「限時提供」），
   最準的查法是官方 Pricing 表：https://opencode.ai/docs/zen/
   名字僅供參考，當下以官網標示 Free 的為準。
3. 換模型不用重做設定，清單裡隨時切換即可。

🔒 隱私守則（免費模型特別重要，請直接遵守）：
免費期間，你打進去的內容有可能被拿來訓練改進模型。
❌ 不要丟：學生姓名、學號、成績、家長聯絡方式等任何個資
✅ 可以丟：公開教材、自己寫的教案、示範用的假資料
需要處理真實學生資料時，先把姓名換成「學生A、學生B」。

─────────────────────────────
第五步：第一次動手測試（三關驗證，不要跳過）
─────────────────────────────
「AI 有回話」不代表通了——有些模型很會聊天但不會做事。
真正有用的驗證是叫它「動手建一個檔案」。

在你的專案資料夾裡，貼這段話給 AI：

  請在目前這個資料夾建立一個檔案叫 test.txt，
  內容寫一行：OpenCode 連線成功。
  建立完成後，把這個檔案的內容讀出來給我看。

三關都要過才算通過：
① 會回話：AI 有正常中文回應，不是錯誤訊息
② 會動手：看得到它「呼叫工具寫檔案」的動作
   （跳出詢問是否允許時 → 選允許）
③ 檔案真的在：打開資料夾，test.txt 存在且內容正確

只有①沒有②③ → 這顆免費大腦不會用工具，
換另一個 Free 模型重測。測完把 test.txt 刪掉。

─────────────────────────────
第六步：貼懶人包，叫 AI 自己蓋地基（#00 必裝）
─────────────────────────────
🧰 先認識：終端機（PowerShell）
終端機就是電腦裡「打指令」的地方，黑色視窗開頭長這樣：
  PS C:\Users\你的名字>
待會 AI 安裝環境時，你會看到它在終端機裡跑指令——
不用會打，看得懂它在做事就好。（Windows 開始功能表搜尋
PowerShell 可以自己打開來看看；AI 通常會用內建的。）

把下面這段「魔法咒語」整段貼給 AI：

  這是 OpenCode 懶人包全集
  https://github.com/mathruffian-dot/opencode-lazy-packs
  請讀取 repo 內容，列出所有可用的懶人包，問我要裝哪些。

AI 會自己讀取清單，列出 11 包問你要裝哪些。
回答：「裝 00 環境建置」。

接下來 AI 就會自動完成：
- 偵測你電腦已經裝了什麼（缺的才裝，不亂裝）
- 安裝 Git（時光機）、GitHub CLI gh、Node.js（地基）、uv（工具箱）
- 每裝一項就驗證版本，最後回報一張結果表

🖐️ 過程中需要你做的兩件事：
1. 跳出「你要允許此應用程式變更你的裝置嗎？」（UAC 彈窗）
   → 按「是」。AI 不能替你按，它會停在那裡等你。
2. AI 說「請重開終端機」→ 照做。
   （剛裝好的工具，舊視窗看不到，重開才找得到。）

最後補一句：「再幫我設定 Git 的使用者名字與 Email」
（git config），AI 會問你名字並設好——
第 7 章上傳部署時才不會卡住。

看到回報表上 Git、Node.js 全部打勾＝地基完工！
以前你要自己跑建材行買鋼筋水泥，現在員工自己叫貨、
自己施工、自己驗收——這就是 AI Agent。

─────────────────────────────
第七步（選配）：#02 內部工具包——長出更厲害的手腳
─────────────────────────────
同樣用上面的咒語，這次跟 AI 說要裝「02 file-toolkit」。
這一包含三類互相獨立的工具：

A 文件處理（今天就用得到）
  Word/Excel/PPT/PDF/圖片/QR Code 十件套。
  裝完你可以直接說：
  「讀這份名單 Excel，套進獎狀模板，每人產一份」
  「把這些 PDF 合併」「把這 5 個連結各生一張 QR Code」

B 影音工具（可跳過，後面剪影片課才用）
  yt-dlp 下載影片字幕當逐字稿、FFmpeg 轉檔。

C 語音 Edge-TTS（30 秒聽到聲音的 Wow 時刻）
  讓 AI 用台灣中文開口唸結論給你聽，免金鑰免付費。
  裝完對它說：「把剛剛的結論用語音唸給我聽」。

⏱ 課堂時間不夠？先裝 A 和 C（今天要用），
B 回家自己補。三段互不影響，一段失敗不拖累其他段。

─────────────────────────────
【補充 1】進階：CLI 版怎麼連接
─────────────────────────────
熟悉終端機的人也可以在 CLI 版輸入 /connect 指令連接：
啟動 opencode → 輸入 /connect → 方向鍵選 OpenCode Zen
→ 貼上金鑰 → opencode auth list 確認。
初學者用桌面版就好，這段看過即可。

─────────────────────────────
【補充 2】金鑰不小心外洩怎麼辦
─────────────────────────────
如果不小心把金鑰貼到聊天室、群組或文件：
立刻回到 https://opencode.ai/auth 的 Console，
把那把金鑰刪除／停用，重新建一把新的，再重新連接一次。
金鑰就像提款卡，掉了馬上掛失重辦。

─────────────────────────────
【補充 3】免費模型突然要收費了？
─────────────────────────────
免費是「限時提供」，隨時可能結束。
出現餘額不足或要求付款的錯誤，代表那顆模型的免費期到了：
回官方 Pricing 表（opencode.ai/docs/zen）重查現在哪些標 Free，
換一顆就好，金鑰和設定都不用動。

【常見陷阱】
═══════════════════════════════

陷阱 1：打字進去完全沒反應，或出現 No providers configured
原因：裝好了但還沒接上模型（沒做第一、二步）——不是你裝壞了。
解決：照第一步申請金鑰、第二步連接 OpenCode Zen，重啟後再試。

陷阱 2：連接完，模型清單裡還是沒東西（或改了 MCP 沒生效）
原因：沒有「完全關閉」就重開，新的設定沒被載入。
解決：工作管理員找到 OpenCode 按「結束工作」，再重新開啟。

陷阱 3：選到 OpenCode Go 或付費模型，突然要收費
原因：Go 是付費訂閱制，長得跟 Zen 很像；有些模型不在免費名單。
解決：認明 OpenCode Zen；模型挑名字有 Free 的，
     以官方 Pricing 表為準。

陷阱 4：金鑰貼錯，出現 Unauthorized / invalid api key
原因：貼到一半、前後多空白、被自動換行切斷。
解決：先貼到記事本確認整串在同一行，重新複製再連接一次。

陷阱 5：學校網路連不上、一直轉圈逾時
原因：校園網路可能擋掉 AI 服務的網域。
解決：用手機熱點測一次——能通就是校網問題，
     請資訊組放行 opencode.ai 與 auth.opencode.ai。

陷阱 6：AI 卡住不動，好像當機
原因：多半不是當機，是它在等你——UAC 授權彈窗沒人按「是」，
     或它請你重開終端機你還沒做。
解決：看一下螢幕有沒有彈窗要你確認；它說什麼就配合做什麼。

陷阱 7：AI 會聊天，但不會建檔案
原因：這顆免費模型的「工具呼叫」能力不足。
解決：換另一個 Free 模型，重跑步驟五的三關驗證。
     （同一個任務失敗兩次以上，先換模型再懷疑自己。）

═══════════════════════════════
【練習】動手做
═══════════════════════════════

目標：走完六大步，親眼看到 AI 從「空殼」變成「會做事的員工」。

1. 到 opencode.ai/auth 註冊 → 建立 API Key → 複製存好。
2. OpenCode：Settings → Providers → OpenCode Zen → Connect
   → 貼上金鑰 → 完全關閉再重開。
3. 新建專案指定乾淨資料夾，Settings 改繁體中文。
4. 模型清單挑一顆 Free 模型。
5. 三關驗證：請它建立 test.txt 再讀出來
   （①會回話②會動手③檔案真的在），測完刪除。
6. 貼懶人包咒語 → 「裝 00 環境建置」
   → 配合 UAC 彈窗與重開終端機
   → 看懂回報表（git、node 都有版本號）
   → 再請它設定 Git 使用者名字與 Email。
7. （選配）加碼裝 #02 工具包的 C 段，
   聽 AI 用台灣腔開口說第一句話。

哪一步卡住，把畫面上的錯誤訊息原封不動貼給 AI，請它幫你修；
修不了的對照【常見陷阱】找答案。

【本節重點】
═══════════════════════════════

1. OpenCode 只是駕駛座，接上模型才會思考。
   OpenCode Zen 是官方模型總機：一組金鑰通多個免費模型。
2. 流程背起來：
   ① opencode.ai/auth 申請金鑰（只顯示一次！）
   ② Settings → Providers → OpenCode Zen → Connect → 貼上
      → ⚠️ 完全關閉重啟
   ③ 專案設定：乾淨資料夾＋繁體中文＋Git 資料庫
   ④ 選名字有 Free 的模型（免費期會變，以官方 Pricing 表為準）
3. 三關驗證：會回話、會動手、檔案真的在——只會聊天不算通。
4. 懶人包咒語一貼，AI 自己偵測、安裝、驗證、回報：
   #00 環境建置必裝（Git/GitHub CLI/Node.js/uv）；
   UAC 彈窗自己按「是」、叫你重開終端機就照做。
5. #02 內部工具包選配：A 文件處理（獎狀/成績表/QR Code）、
   B 影音（可跳過）、C 語音（AI 開口說台灣話）；時間不夠先 A+C。
6. 🔒 隱私守則：免費模型可能拿輸入內容訓練，
   學生個資絕對不打進去；敏感資料先匿名化。
7. 金鑰外洩＝提款卡掉了：回 Console 立刻刪除重建。
8. 從這一章起，你有了第一個真正「聽懂目標、動手做事、
   自動回報」的 AI 員工——下一章教你看懂它的完整工作流程。
