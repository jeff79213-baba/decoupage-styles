  安裝 opencode（AI 助理本體，主角登場）
  第 2 章｜AI 課程第三課
  動手安裝 ｜ 需要一台 Windows 電腦
═══════════════════════════════

【說明】為什麼學這章
這一章的主角要登場了！它就是 opencode——「AI 助理本體」。
你打字它做事，是整個課程的靈魂。前面辛苦裝好的 Node.js、npm，
都是為了讓它能跑起來而存在；沒有它，前面裝的東西全都派不上用場。

我們用「僱用員工的第一天」來比喻，你一下就懂：
- 安裝 = 把員工帶進公司
  你對員工喊一聲「今天開始你來上班」，員工就正式入職了。
  對應到電腦，就是把 OpenCode Desktop 下載安裝進電腦裡。
- 設定 API Key = 給員工發薪帳戶（接上大腦）
  員工要有領錢的帳戶才願意工作。opencode 的「大腦」是雲端上的
  AI 模型，你必須給它一張「識別證」（API 金鑰），它才願意幫你
  思考做事。沒有這張識別證，AI 助理只會發呆。
- 初始設定 = 幫員工備好辦公室
  新建專案資料夾（乾淨的辦公室）、改成繁體中文（聽得懂的語言）、
  建立 Git 資料庫（上一章裝好的時光機，從第一天就開始記錄）。

所以這一章就四件事：帶員工進公司（安裝）、發薪（API Key）、
接上大腦（啟用連接）、備好辦公室（初始設定）。
四件都完成，你就可以開始和 AI 對話了！

═══════════════════════════════
【操作步驟】
═══════════════════════════════

─────────────────────────────
第一步：下載並安裝 OpenCode Desktop
─────────────────────────────
1. 前往 OpenCode 官方網站，下載桌面版（Desktop）。
   找不到官網就用 Google 搜尋「OpenCode desktop」，認明官網再下載。
2. 根據你的作業系統選擇正確版本：
   - Windows：選 Windows 版
   - Mac：M 系列晶片（Apple Silicon）請選 Apple Silicon 版
3. 下載後直接安裝、開啟，就像裝 LINE 一樣簡單。

看到 opencode 的視窗打開，員工就已經進公司了！

─────────────────────────────
第二步：申請 OpenRouter 免費 API Key
─────────────────────────────
opencode 的「大腦」是雲端上的 AI 模型，需要一張識別證
（API 金鑰）才能跟大腦通話。我們用完全免費的 OpenRouter：

⏸ 授權點（請停下來，這一步要你親自動手）：
API 金鑰是你的私密資料，AI 不能幫你申請、也不可以亂猜。
必須由你本人申請一組金鑰，再貼給 opencode。

1. 用 Google 搜尋「OpenRouter」，進到官網註冊帳號（完全免費）。
2. 點選「Get API Key」→「New Key」。
3. 為金鑰取一個名字（例如：open code 0517），點「Create」生成。
4. 複製畫面上產生的那組金鑰字串。
   ⚠️ 金鑰通常只顯示一次，立刻複製存好（貼到記事本或手機備忘錄），
   下一步就要用。

─────────────────────────────
第三步：於 OpenCode 啟用免費 AI 連接
─────────────────────────────
拿到金鑰，回到 OpenCode 把大腦接上：

1. 在 OpenCode 中選擇「連接提供商」（Connect Provider）
2. 點選「OpenRouter」
3. 把剛才複製的 API Key 貼上，按「提交」

看到連線成功的提示，就代表大腦（CPU）接上了，
AI 從「只會發呆」變成「會思考做事」！

─────────────────────────────
第四步：專案與語系初始設定
─────────────────────────────
員工進公司、薪水也發了，最後幫他備好辦公室：

1. 新建一個專案，並於本地建立並指定專案資料夾
  （例如：Open Code 0517）。
   白話：先在你的電腦上新增一個全新的空資料夾，
   再讓 OpenCode 打開這個資料夾當作工作的地方。
   就像給員工一間「乾淨的辦公室」，他才不會把你的檔案弄亂。

2. 進入設定（Settings），將介面語言更改為「繁體中文」。
   白話：讓員工跟你說同一種語言，後面溝通才順。

3. 點選「建立 Git 資料庫」。
   白話：把上一章裝好的「Git 時光機」接到這間辦公室，
   從第一天起，每次改動都有備份點，做壞了隨時倒得回去。

完成以上四步，萬事俱備！直接打字跟 AI 說話，第一次對話可以這樣開場：

─────────────────────────────
你：你好，請幫我介紹一下你自己，你是做什麼的？
    我是完全沒寫過程式的新手。

AI：你好！我是 opencode，你的 AI 助理。我可以聽懂你的需求，
    幫你讀寫檔案、執行指令，甚至建立整個專案。
    你不用寫程式，只要用白話跟我說「你想做什麼」，我就動手做。

你：太好了！那我要怎麼開始？

AI：很簡單，你只要告訴我你的第一個任務就好，
    例如「幫我建立一個資料夾」，我就照做給你看。
─────────────────────────────

看到 AI 真的回應你，代表金鑰有效、設定正確，
你正式通過「員工上班第一天」的考驗了！

─────────────────────────────
【補充 1】選擇模型（CPU＝AI 的大腦）
─────────────────────────────
連上 OpenRouter 後，可以選擇要用哪顆「大腦」：
強烈推薦選擇「DeepSeek V4 Flash (Free)」——免費，
具備 200K 的上下文記憶體，實測聯網搜尋與執行力非常給力。
（講師實測通義千問免費版當天連線較不穩定，卡住就換模型。）

─────────────────────────────
【補充 2】載入懶人包，自動部署 MCP
─────────────────────────────
將過往的「AI Agent 環境建置懶人包」（提示詞/組態）直接丟給它，
它就會自動幫你部署好 MCP，順利連接上本地硬碟、Obsidian 或
遠端的 NotebookLM。
（MCP 就像幫員工接上「外部工具插座」：讀硬碟檔案、開筆記本、
連雲端文件，都要靠這些插座。）

⚠️ 重要約束：
若調整了 MCP 擴充元件，OpenCode 不會自動重啟。
請務必手動在工作管理員中將它「結束工作」，再重新開啟，
才能成功載入新環境。
（白話：幫員工换了新工具之後，要先叫他下班再上班，新工具才生效。）

─────────────────────────────
【補充 3】進階安裝方式：CLI 指令版
─────────────────────────────
如果你熟悉終端機，也可以不打開桌面版，改用指令安裝：
在終端機輸入 npm install -g opencode-ai 安裝，
輸入 opencode --version 驗證，輸入 opencode auth login 設定金鑰
（選 openrouter、貼上金鑰），最後輸入 opencode 啟動對話。
初學者用桌面版就好，這段看過即可。

═══════════════════════════════
【常見陷阱】
═══════════════════════════════

陷阱 1：忘了設定 API 金鑰，AI 完全不回應
原因：opencode 裝好了，但「發薪帳戶」沒設定——沒有識別證，
     它連不上雲端大腦，你送出的任何訊息都石沉大海。
解決：回到第二步重新申請金鑰，再到第三步「連接提供商」貼上提交，
     重新啟動 opencode。

陷阱 2：金鑰貼錯或失效，AI 回應怪怪的
原因：金鑰前後多貼了空白、複製到舊的/失效的金鑰，或額度用完。
解決：回 OpenRouter 重新產生一組新金鑰，重新複製貼上一次；
     注意不要多複製到空格。

陷阱 3：Mac 用戶裝錯版本
原因：Mac 分 Intel 晶片和 M 系列（Apple Silicon）兩種，
     裝錯版本可能跑不動或怪怪的。
解決：確認自己的晶片類型，M 系列一律選 Apple Silicon 版。

陷阱 4：調整 MCP 後新環境沒生效
原因：OpenCode 不會因為你改了 MCP 擴充元件就自動重啟，
     新工具一直沒被載入，AI 卻好像「看不到硬碟、開不了筆記」。
解決：打開工作管理員，找到 OpenCode 按「結束工作」，
     再重新開啟，讓它帶著新環境重新上工。

陷阱 5：免費模型連線不穩、回應卡住
原因：部分免費模型（如通義千問免費版）某些時段連線較不穩定。
解決：把模型切換成 DeepSeek V4 Flash (Free) 再試一次；
     還是不行就等幾分鐘，通常一下子就恢復。

陷阱 6：沒有建專案資料夾，直接在雜亂的地方開工
原因：opencode 是在「開啟的資料夾」裡工作的。如果隨便在一個
     塞滿檔案的地方開工，AI 可能動到不相干的檔案。
解決：每次開新專案，都先建一個乾淨的新資料夾再指定給它；
     同時記得勾「建立 Git 資料庫」，讓時光機從第一天就開始記錄。

═══════════════════════════════
【練習】動手做
═══════════════════════════════

目標：照著四步流程走完，成功讓 AI 回覆你一句話。

步驟：
1. 到 OpenCode 官網下載桌面版（Windows／Mac Apple Silicon），
   安裝並開啟。

2. 到 OpenRouter 註冊 → Get API Key → New Key → 命名
  （例如 open code 0517）→ Create → 複製金鑰。

3. 回 OpenCode：「連接提供商」→ OpenRouter → 貼上金鑰 → 提交。

4. 新建專案並指定本地資料夾（例如 Open Code 0517），
   Settings 改繁體中文，點選「建立 Git 資料庫」。

5. 打一句話給 AI：
     「你好，請幫我介紹一下你自己。」
   等 AI 回覆你一句話，就成功了！

完成以上 5 步，你就正式把「AI 員工」請進門、發好薪、接上大腦、
還幫他備好了辦公室。
如果哪一步卡住，把畫面上的錯誤訊息原封不動貼給 AI，請它幫你修。

【本節重點】
═══════════════════════════════

1. opencode 是「AI 助理本體」，是整個課程的主角——
   前面裝的 Node.js、npm 都是為了讓它跑起來而存在的。
2. 四步流程背起來：
   ① 官網下載 OpenCode Desktop（Windows／Mac M系列選 Apple Silicon）
   ② OpenRouter 註冊 → Get API Key → New Key → 命名 → Create
      → 複製金鑰（只顯示一次！）
   ③ OpenCode「連接提供商」→ OpenRouter → 貼上金鑰 → 提交
   ④ 新建專案＋指定本地資料夾 → Settings 改繁體中文
      → 點選「建立 Git 資料庫」
3. ⚠️ API 金鑰是私密資料，必須由你自己申請、自己貼，AI 不能代辦。
4. 模型推薦 DeepSeek V4 Flash (Free)（200K 上下文）；卡住就換模型。
5. ⚠️ 改了 MCP 一定要手動重啟（工作管理員「結束工作」再開啟），
   新環境才會生效。
6. 「建立 Git 資料庫」就是把第 1 章的時光機接上新專案——
   從第一天起每次改動都有備份點。
7. 從現在開始，你有了第一個真正會「聽懂目標、動手做事」的 AI 員工，
   接下來課程就要教怎麼讓它幫你做整個專案。
