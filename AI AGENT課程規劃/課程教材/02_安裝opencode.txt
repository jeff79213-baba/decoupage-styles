  安裝 opencode（AI 助理本體，主角登場）
  第 2 章｜AI 課程第三課
  動手安裝 ｜ 需要一台 Windows 電腦
═══════════════════════════════

【說明】為什麼學這章
這一章的主角要登場了！它就是 opencode——「AI 助理本體」。
你打字它做事，是整個課程的靈魂。前面辛苦裝好的 Node.js、npm，
都是為了讓它能跑起來而存在；沒有它，前面裝的東西全都派不上用場。

我們用「僱用員工的第一天」來比喻，你一下就懂：
- 安裝 = 把員工帶進公司
  你對員工喊一聲「今天開始你來上班」，員工就正式入職了。
  對應到電腦，就是輸入安裝指令，把 opencode 裝進電腦裡。
- 設定 = 給員工發薪帳戶
  員工要有領錢的帳戶才願意工作。opencode 的「大腦」是雲端上的
  AI 服務，你必須給它一張「識別證」（API 金鑰），證明你是付費
  用戶，它才願意回答你。沒有這張識別證，AI 助理只會發呆。

所以這一章就兩件事：把員工帶進公司（安裝），然後給他發薪帳戶（設定）。
兩件都完成，你就可以開始和 AI 對話了！

═══════════════════════════════
【操作步驟】
═══════════════════════════════

第一步：打開終端機
在 Windows 左下角開始功能表搜尋「PowerShell」或「命令提示字元」，
按 Enter 打開它。這是你打指令的地方，叫做「終端機」。
（還記得嗎？上一章裝 Node 和 Git 就是在這裡打指令的。）

─────────────────────────────
第二步：把員工帶進公司（安裝 opencode）
─────────────────────────────
在終端機輸入下面這一行，然後按 Enter：

  npm install -g opencode-ai

這句話的白話翻譯：用「應用程式商店」npm，安裝一個叫做
「opencode-ai」的全域工具。裝好之後，它會變成電腦裡的一個「員工」，
在任何資料夾都能呼叫它。

看到類似「added 1 package」或「added N packages」的訊息，
就代表安裝完成，員工入職了！

─────────────────────────────
第三步：確認員工在場（驗證版本）
─────────────────────────────
安裝完，輸入驗證指令：

  opencode --version

你會看到類似這樣的一行版本號：
─────────────────────────────
1.16.2
─────────────────────────────
看到版本號，代表 opencode 真的裝好了，AI 助理本體在線！

─────────────────────────────
第四步：給員工發薪帳戶（設定 API 金鑰）
─────────────────────────────
opencode 的「大腦」在雲端，它需要一張「識別證」才能跟大腦通話。
這張識別證叫「API 金鑰」，是你向 AI 服務提供者申請來的，
證明你是付費用戶。

⏸ 授權點（請停下來，這一步要你親自動手）：
API 金鑰是你的私密資料，AI 不能幫你申請、也不可以亂猜。
必須由你本人到提供者網站申請一組金鑰，再貼給 opencode。

下面以最常用的提供者 OpenRouter 為例，帶你一步步完成：

── 4-1：到 OpenRouter 網站註冊帳號 ──

1. 打開瀏覽器，網址列輸入：https://openrouter.ai
2. 點右上角「Sign In」或「Get Started」
3. 用 Google 帳號或 email 註冊（跟註冊一樣簡單）
4. 註冊完成後，你會進入後台畫面

── 4-2：產生 API 金鑰 ──

1. 在後台畫面左側選單，找到「Keys」（或網址列直接輸入
   https://openrouter.ai/keys）
2. 點「Create Key」或「+ Create Key」
3. 給它一個名字（例如「opencode」），然後點「Create」
4. 畫面會顯示一組以「sk-or-」開頭的字串，例如：
   sk-or-v1-abc123def456ghi789...
5. ⚠️ 這組金鑰只會顯示一次！立刻複製並存好。
   建議貼到手機備忘錄或記事本，等一下要貼給 opencode。

── 4-3：把金鑰貼給 opencode ──

回到終端機，輸入下面這一行，然後按 Enter：

  opencode auth login

它會問你要用哪一個提供者——選「openrouter」。
然後它會要你貼上 API 金鑰——把剛才複製的那組貼上去，按 Enter。

看到類似「Login successful」或「設定完成」的訊息，就成功了！

（如果你用的是其他提供者，例如 NVIDIA，流程類似：
到 build.nvidia.com 註冊 → 產生 API Key → opencode auth login 選 nvidia → 貼上金鑰。）

（進階：你也可以在 opencode 的設定檔 opencode.json 裡指定要用
哪一個模型，例如 {"model": "你選擇的提供者/模型名稱"}。
初學者可以先略過，用預設的就好。）

─────────────────────────────
第五步：叫員工上班（啟動 opencode）
─────────────────────────────
設定好金鑰後，在終端機輸入：

  opencode

按下 Enter，你就會進入和 AI 的對話畫面——「員工」正式開始上班了！

─────────────────────────────
第六步：第一次對話（你與 AI 的對話框示意）
─────────────────────────────
進入對話畫面後，你就直接打字跟 AI 說話。第一次對話可以這樣開場：

─────────────────────────────
你：你好，請幫我介紹一下你自己，你是做什麼的？
    我是完全沒寫過程式的新手。

AI：你好！我是 opencode，你的 AI 助理。我可以聽懂你的需求，
    幫你讀寫檔案、執行指令，甚至建立整個專案。
    你不用寫程式，只要用白話跟我說「你想做什麼」，我就動手做。
    例如你想做一個「早餐點餐網頁」，跟我說一聲，我就一步步幫你完成。

你：太好了！那我要怎麼開始？

AI：很簡單，你只要告訴我你的第一個任務就好。
    例如「幫我建立一個資料夾」，我就照做給你看。
─────────────────────────────

看到 AI 真的回應你，代表金鑰有效、設定正確，你正式通過「員工
上班第一天」的考驗了！

═══════════════════════════════
【常見陷阱】
═══════════════════════════════

陷阱 1：忘了設定 API 金鑰，AI 完全不回應
原因：opencode 裝好了，但「發薪帳戶」沒設定——沒有識別證，
     它連不上雲端大腦，你送出的任何訊息都石沉大海。
解決：回到【操作步驟】第四步，執行 opencode auth login，
     把你自己申請的 API 金鑰貼上去，再重新啟動 opencode。

陷阱 2：金鑰貼錯或過期，AI 回應怪怪的
原因：金鑰前後多貼了空白、提供者名稱拼錯，或金鑰額度用完、到期了。
解決：檢查金鑰有沒有前後多餘空白、提供者名稱有沒有拼錯；
     如果都不對，到提供者的後台重新產生一組新金鑰再試。

陷阱 3：在錯誤的資料夾啟動
原因：opencode 開啟後，是在「目前所在資料夾」裡工作的。
     如果你的檔案放在「專案A」，卻在「專案B」資料夾打開 opencode，
     它就會找不到檔案、或改到錯的地方。
解決：啟動 opencode 之前，先確認終端機顯示的路徑（例如
     PS C:\Users\你的名字\專案A>）就是你想做事的資料夾。
     不確定的話，先輸入 cd 切換到正確資料夾，再輸入 opencode。

陷阱 4：輸入 opencode 顯示「找不到」或「無法辨識」
原因：通常是 Node.js 沒裝好，或裝完後沒有重新打開終端機。
解決：確認 Node.js 裝好了（回到上一章，輸入 node --version 驗證）；
     關掉終端機重新打開，再試一次 opencode --version。

═══════════════════════════════
【練習】動手做
═══════════════════════════════

目標：成功開啟與 AI 的第一段對話，並讓 AI 回覆你一句話。

步驟：
1. 打開終端機，輸入並執行（打完按 Enter）：
     opencode --version
   確認看到版本號 1.16.2。（看不到就回到【常見陷阱】找答案）

2. 確認 API 金鑰已設定（忘了就執行 opencode auth login，
   貼上你自己申請的金鑰）。

3. 輸入 opencode，按下 Enter，進入對話畫面。

4. 打一句話給 AI，例如：
     「你好，請幫我介紹一下你自己。」
   等 AI 回覆你一句話，就成功了！

5. 想結束對話時，輸入「再見」或按 Ctrl+C 退出 opencode。

完成以上 5 步，你就正式把「AI 員工」請進門、也發好薪了。
如果哪一步卡住，把終端機上的錯誤訊息原封不動貼給 AI，
請它幫你修。

【本節重點】
═══════════════════════════════

1. opencode 是「AI 助理本體」，是整個課程的主角——
   前面裝的 Node.js、npm 都是為了讓它跑起來，其他工具也都是
   為了讓它更強才存在的。
2. 安裝 = 把員工帶進公司：npm install -g opencode-ai。
3. 設定 = 給員工發薪帳戶：opencode auth login + 貼上你自己的 API 金鑰。
   ⚠️ API 金鑰是私密資料，必須由你自己申請、自己貼，AI 不能代辦。
4. 驗證三件事：opencode --version 看到 1.16.2、
   金鑰設定成功、opencode 啟動後 AI 會回應你。
5. 在「正確的資料夾」啟動 opencode——它是在你目前所在資料夾工作。
6. 從現在開始，你有了第一個真正會「聽懂目標、動手做事」的 AI 員工，
   接下來課程就要教怎麼讓它幫你做整個專案。
