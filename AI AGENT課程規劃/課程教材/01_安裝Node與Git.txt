  安裝 Node 與 Git（地基與時光機）
  第 1 章｜AI 課程第二課
  動手安裝 ｜ 需要一台 Windows 電腦
═══════════════════════════════

【說明】為什麼學這章
這一章要幫你的電腦打好兩樣最重要的地基，後面的課程才走得下去：

- Node.js（「電腦裡的一座小型工廠」）
  讓 AI 工具跑起來的底層引擎。沒有它，任何 AI 程式都開不了機。
- npm（「應用程式商店」）
  跟著 Node 一起來的，負責下載、安裝 AI 工具的地方，跟手機裝 App 一樣。
- Git（「時光機 + 檔案保險箱」）
  每次改動都存一個備份點，做壞了能倒回。沒有它，改壞的檔案就回不去。

用蓋房子來比喻：先打地基（Node.js），再架鋼骨（Git），
後面才有能力裝上 AI Agent（opencode）跟各種輔助工具。

這一章你只要跟著做，裝好之後在終端機打幾個指令，
看到版本號碼跑出來，就代表地基打好了。

═══════════════════════════════
【操作步驟】
═══════════════════════════════

第一步：打開終端機
在 Windows 左下角開始功能表搜尋「PowerShell」或「命令提示字元」，
按 Enter 打開它。這就是你之後打指令的地方，叫做「終端機」。

打開後你會看到一個黑色（或藍色）視窗，前面有一個游標閃爍，像這樣：
─────────────────────────────
Windows PowerShell
PS C:\Users\你的名字>
─────────────────────────────
後面所有「在終端機輸入 XXX」的意思，就是打完按 Enter。

─────────────────────────────
第二步：安裝 Node.js（先蓋地基）
─────────────────────────────
Node.js 是「小型工廠」，所有 AI 工具都要站在它上面才跑得起來。

安裝方式（二選一，建議用第一個）：

方法 A：用官方網站下載（推薦初學者）
1. 打開瀏覽器，到 Node.js 官方網站：https://nodejs.org/
2. 點黃色按鈕「下載 LTS 版本」（LTS 代表最穩定，選它就對了）
3. 下載完，雙擊安裝檔，一路按「下一步（Next）」到底，最後按「安裝（Install）」
4. 安裝過程中，如果有勾選方塊（例如 Add to PATH），保持預設「打勾」就好

方法 B：用 winget 指令（進階，但更快）
在終端機輸入：
  winget install OpenJS.NodeJS.LTS
看到「已成功安裝」就完成了。

安裝完，回到終端機，輸入驗證指令：
  node --version

你會看到類似這樣的一行版本號：
─────────────────────────────
v26.1.0
─────────────────────────────
看到「v 開頭的版本號」就代表 Node.js 裝成功了！

─────────────────────────────
第三步：驗證 npm（應用程式商店有沒有跟著開）
─────────────────────────────
npm 是「應用程式商店」，它跟著 Node.js 一起裝好，不用另外安裝。
只要確認它在就好，在終端機輸入：
  npm --version

你會看到：
─────────────────────────────
11.13.0
─────────────────────────────
看到這串數字，代表「應用程式商店」開張了，
後面章節要裝 AI 工具（opencode 等）全靠它。

─────────────────────────────
第四步：安裝 Git（架鋼骨、裝時光機）
─────────────────────────────
Git 是「時光機 + 檔案保險箱」。每次改動都存一個備份點，
做壞了可以倒回，這是讓 AI 幫你改檔案時「不怕改壞」的關鍵。

安裝方式（二選一，建議用第一個）：

方法 A：用官方網站下載（推薦初學者）
1. 到 Git 官方網站：https://git-scm.com/
2. 點頁面上的「Download for Windows」
3. 下載完，雙擊安裝檔，一路按「下一步（Next）」
4. 中間會有很多設定畫面，全部保持預設、一路「Next」到底
   （初學者不要亂改設定，改了可能反而不能用）
5. 最後按「Install」，看到「Finish」就完成

方法 B：用 winget 指令
在終端機輸入：
  winget install Git.Git

安裝完，回到終端機，輸入驗證指令：
  git --version

你會看到：
─────────────────────────────
git version 2.54.0
─────────────────────────────
看到「git version」開頭，代表時光機裝好了。

─────────────────────────────
第五步：告訴 Git 你是誰（時光機要記名）
─────────────────────────────
Git 會在每次存檔點上面蓋一個章，寫下「這是誰改的」。
所以要先告訴它你的名字和 Email，只要設一次就好。

在終端機輸入（把「你的名字」「your@email.com」換成你自己的）：
  git config --global user.name "你的名字"
  git config --global user.email "your@email.com"

這兩個指令輸入時不會顯示任何東西，沒報錯就代表設定成功。
可以這樣確認，輸入：
  git config --global user.name
會把你剛剛設的名字印出來，看到名字就代表成功。

═══════════════════════════════
【常見陷阱】
═══════════════════════════════

陷阱 1：輸入 node 顯示「找不到 node」或「不是內部或外部命令」
原因：PATH 沒設好，或安裝後沒有重新打開終端機。
解決：
- 先關掉終端機，重新開一個再輸入一次
- 如果還是不行，重新安裝 Node，安裝時確認「Add to PATH」保持打勾
- 還沒解決就照上面的對話框示範，貼給 AI 幫你看

陷阱 2：裝了錯的版本（例如裝了測試版、太舊的版本）
原因：Node 官方網站有兩個按鈕，LTS（穩定）跟 Current（最新測試）。
     初學者選到 Current，之後容易遇到怪問題。
解決：一律裝「LTS」版本，最穩定、最不會出狀況。

陷阱 3：Git 安裝時亂改設定
原因：安裝過程有很多設定畫面，例如選編輯器、改預設分支名稱，
     初學者看不懂就亂選，之後用起來卡卡的。
解決：全部保持預設，一路「Next」到底就好。

陷阱 4：git config 打完沒有任何反應，以為失敗
原因：Git 設定成功本來就不會顯示東西，沒報錯就是成功。
解決：用 git config --global user.name 確認，會印出你的名字。

═══════════════════════════════
【練習】動手做
═══════════════════════════════

打開終端機，把這三個指令依序打一遍（打完按 Enter）：

  node --version
  npm --version
  git --version

目標：
- node --version 顯示 v26.1.0（至少是 v20 以上都算成功）
- npm --version 顯示 11.13.0（一長串數字就對了）
- git --version 顯示 git version 2.54.0（看到 git 就對了）

三個都看得到，這一章就完成了。
如果哪一個顯示「找不到」或報錯，回到上面的【常見陷阱】找答案，
或者把錯誤訊息原封不動貼給 AI，請它幫你修。

【本節重點】
═══════════════════════════════

1. Node.js 是「小型工廠」，是 AI 的地基——沒有它，任何 AI 程式都開不了機。
2. npm 是「應用程式商店」，跟著 Node 一起裝好——裝完 Node，
   「應用程式商店」npm 也跟著有了，不用另外裝。
3. Git 是「時光機 + 檔案保險箱」——改壞了可以倒回，不怕做錯。
4. 驗證三連招：node --version、npm --version、git --version，
   看到版本號就是成功。
5. 初學者一律裝 LTS 版本、安裝時保持預設，不要亂改設定。
