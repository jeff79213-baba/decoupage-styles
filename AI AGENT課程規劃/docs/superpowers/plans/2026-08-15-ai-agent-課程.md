# AI Agent 課程專案 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 產出「AI Agent 課程專案」——一份給新 Agent 自動執行的冷啟動手冊 + 一套給無程式基礎者學習的 9 章教材 + HTML 教學首頁。

**Architecture:** 三層結構共享同一份「環境藍圖」事實來源。先做環境分析（事實），再做冷啟動手冊（指令式，依賴環境分析），接著做 9 章課程教材（教學式，每章依賴環境分析與冷啟動手冊的內容），最後做 HTML 首頁（統整入口，依賴全部章節）。

**Tech Stack:** Markdown 文件、TXT 教材（沿用考卷變教材格式）、單檔 HTML（localStorage 記進度）。

## Global Constraints

- **所有套件/工具/安裝項目都必須有「🗣️ 白話說明」欄位**：用一句生活化比喻解釋這是什麼、幫你做什麼、為什麼非裝不可。禁止只貼官方定義。
- 所有版本號以開發機實測為準，不杜撰。實測版本：Node v26.1.0、npm 11.13.0、opencode 1.16.2、Git 2.54.0、gh 2.92.0、firebase-tools 15.20.0、Python 3.12.10、PowerShell 5.1。
- 目標讀者：完全無程式基礎的一般人，熟悉日常電腦操作。語言生活化、多用比喻、避免程式術語堆疊。
- 每章 TXT 教材格式固定：【說明】【操作步驟】【常見陷阱】【練習】【本節重點】。
- 冷啟動手冊每步格式固定（步驟卡）：白話說明 → 執行 → 預期結果 → 驗證 → 授權點 → 若失敗 → 為什麼。
- 檔案路徑一律用英文檔名 + 中文內容；新資料夾 `AI AGENT課程規劃/`。
- 全部文件寫完後，依 AGENTS.md 規則 commit + push。

- [ ] **Step 2: 建立 10 個步驟卡**

每步格式（範例）：
```markdown
## 第 2 步：安裝 Node.js
🗣️ 白話說明：Node.js 是「電腦裡的一座小型工廠」，AI 工具要站著它上面才能跑。
這一步之後，你才會有 npm（應用程式商店）可以下載其他工具。
🖥️ 執行：winget install OpenJS.NodeJS.LTS
✅ 預期結果：顯示安裝完成
🔍 驗證：node --version 應顯示 v22.x 或更高；npm --version 應顯示 11.x
⏸ 授權點：無（winget 自動安裝；若無 winget，改手動下載 https://nodejs.org 的 LTS 安裝檔）
⚠️ 若失敗：到 nodejs.org 下載安裝檔手動安裝，裝完重開終端再驗證
💡 為什麼：沒有 Node.js 就沒有 npm，沒有 npm 就裝不了 opencode——這是整個 AI 環境的地基。
```

10 步內容（來自設計文件）：
1. 檢查環境（OS 版本、網路連線、是否有 winget）
2. 安裝 Node.js（含 npm）→ 驗證 node/npm 版本
3. 安裝 Git → 驗證 git --version；設定 user.name / user.email
4. 安裝 GitHub CLI（gh）→ 驗證 gh --version → ⏸ 授權點：`gh auth login` 需使用者網頁登入
5. 全域安裝 opencode → `npm install -g opencode-ai` → 驗證 opencode --version
6. 設定 opencode 的 AI 服務提供者（API key）→ ⏸ 授權點：需使用者提供/設定金鑰
7. 安裝 Firebase CLI → `npm install -g firebase-tools` → 驗證 firebase --version → ⏸ 授權點：`firebase login` 需使用者網頁登入
8. 安裝 Python + 建立 .venv → 驗證 python --version；用主目錄 .venv 建置（含 10 套件）
9. 安裝 superpowers skills（git clone 至 opencode 套件目錄）+ 複製個人化 skills（hallmark、deploy-workflow）與 AGENTS.md
10. 全環境驗證清單（一個表格列出所有工具與預期版本）

每個步驟卡都必須完整寫出實際指令與預期輸出，不得留空。
