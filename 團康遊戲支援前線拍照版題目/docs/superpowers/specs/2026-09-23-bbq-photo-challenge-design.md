# 烤肉團康支援前線拍照版題目產生器 — 設計文件

日期：2026-09-23

## 背景與問題

原始程式（`chatgpt內碼.txt`）是 ChatGPT 生成的烤肉團康隨機出題器，有下列問題：

1. **無法產生題目**：檔案副檔名是 `.txt`，瀏覽器開啟時當純文字顯示，不會執行 HTML/JS。經實際驗證，`generate()` 邏輯本身正常。
2. **數量可能超出人數**：例如 10 人卻要求 100 根手指，照片湊不出來。
3. 沒有選擇出題範圍的功能，無法配合現場實際擁有的物品。

## 需求

主持人用手機開啟頁面 → 設定人數與勾選可用物品 → 隨機出題 → 複製題目 → 貼到 LINE 群組，讓玩家看題目自行湊齊並拍照。

- 每樣一般物品的數量固定為 1。
- 身體器官品項（手指、手、腳、臉）的數量為「人數 × 30~80%」隨機。
- 出題後主持人可手動修改數字。
- 全員入鏡特殊品項，有機率自動附在題目中，也可手動加入。

## 範圍

- 還原為可執行的 `index.html`（單一檔案、純前端、無外部依賴）。
- 保留原版深色手機版式、計時器、複製功能。
- 部署到 GitHub Pages 或 Firebase Hosting，手機可用網址開啟。

## 介面結構

1. 標題：🔥 支援前線攝影賽
2. **人數設定卡**：輸入 + − 鈕，預設 10 人（範圍 2~30）。
3. **物品勾選卡**：每樣物品一列 `[☑] 物品名稱 · 每人上限`，預設全勾選。取消勾選的物品不會出現在題目中。
4. **出題卡**：顯示題目（數量 × 物品）→ 🎲重新出題 / ✏️修改 / 📋複製 / ➕全員題。
5. **計時器卡**：沿用原有功能。

## 全員入鏡特殊品項

抽中時成品顯示為「📸 全員合照（全員入鏡）」這類，**不計算數量**，要求整隊入鏡。

品項列表：
- 全員合照
- 全員比愛心
- 全員比 YA
- 全員比讚
- 全員跳起來
- 全員手搭肩

## 出題演算法

1. 讀取人數（`peopleCount`，預設 10，範圍 2~30）。
2. 從「已勾選的一般物品」中隨機挑 3~5 樣。
3. 每樣數量：
   - 器官類 → `Math.max(1, Math.round(peopleCount × (0.3 + Math.random() × 0.5)))`（即 30~80%）
   - 一般物品 → 1
4. 有 40% 機率附加 1 個隨機全員品項（顯示於題目最末，附「全員入鏡」標記）。
5. 全員品項數量不參與計分與計時判定。

## 手動修改

- 「✏️修改題目」展開每個物品的數量輸入框，可直接改數量（範圍 1~99）。
- 修改後即時更新題目顯示與複製文字。

## 複製功能

- 沿用原版 `navigator.clipboard.writeText()`，失敗時 fallback `execCommand("copy")`。
- 複製格式範例：

```
🔥 支援前線第 3 題

請在最快時間內拍照完成：

📱 1 手機
☝️ 5 手指
🤲 2 手
📸 全員合照（全員入鏡）

📸 完成後拍照並傳到群組！
```

## 計時器

沿用原版功能：開始/停止/完成/重設，顯示 MM:SS.d。

## 技術決策

- 單一 HTML 檔案，內嵌 CSS / JS，無外部依賴，避免 CDN 斷線影響。
- 儲存副檔名為 `.html`，修正「無法產生題目」的根因。
- 啟動時自動生成第一題。

## 驗證方式

- 以 headless Chrome 開啟 `index.html`，確認題目隨機產出、全員品項有機率出現、複製文字格式正確。
- 手動測試 `setPeople()`, `toggleItem()`, `newQuestion()`, `copyQuestion()`, `addAllMember()` 各按鈕。
- 部署後以手機瀏覽器開啟網址確認可用。
