# 桌面白板隨意畫 — 設計規格

## 概述
單一 HTML 檔案的桌面白板繪圖工具，純前端離線運作，開啟即可使用。

## 核心功能
- 畫筆繪圖（可選顏色、粗細 1~50px）
- 橡皮擦（擦除繪圖層內容）
- 上傳照片作為底圖
- 底圖背景色更換（預設白色）
- 下載為 PNG 圖片
- 複製到剪貼簿（擷取畫面）
- 全擦：清除繪圖層筆跡，保留底圖
- 新畫面：清除全部，回到空白白板
- 自動記憶：關閉前存 localStorage，開啟還原

## 架構
- 雙層 Canvas（bgCanvas 底圖層 + drawCanvas 繪圖層），置於同一個容器內，position 重疊
- 工具列：水平 flexbox，包含所有操作按鈕
- 下載時用離線 canvas 合併兩層，toBlob 產出 PNG

## 按鈕配置
| 按鈕 | 圖示 | 功能 |
|------|------|------|
| 畫筆 | 🖌 | 切換繪圖模式 |
| 橡皮擦 | 🧹 | 切換擦拭模式 |
| 顏色 | ● | 畫筆顏色選擇 |
| 粗細 | ── | 畫筆/橡皮擦大小 |
| 上傳照片 | 📷 | 載入底圖圖片 |
| 底圖顏色 | 🎨 | 更換底圖背景色 |
| 全擦 | ✨ | 清空繪圖層 |
| 新畫面 | 🗑 | 全部清空 |
| 下載 | 💾 | 下載 PNG |
| 擷取 | 📋 | 複製到剪貼簿 |

## 資料持久化
- localStorage key: `whiteboard-draw`（繪圖層資料）
- localStorage key: `whiteboard-bg`（底圖資料，base64）
- 每次繪圖操作結束（mouseup）自動存檔

## 不實作範圍
- 無多圖層管理
- 無文字工具
- 無形狀工具
- 無後端 / 雲端同步
